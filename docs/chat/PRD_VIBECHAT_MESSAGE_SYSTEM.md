# 📋 VibeChat 메시지 시스템 PRD (Product Requirements Document)
**Version:** 2.0
**Date:** 2025-09-22
**Target Release:** v2.0 (Q1 2025)

---

## 🎯 제품 개요

### **목표**
카카오톡 수준의 안정적인 실시간 채팅 시스템 구축
- **메시지 지연 시간**: p95 ≤ 1초
- **동시 접속자**: 1,000명 지원
- **메시지 무손실**: 99.9% 전달 보장
- **서비스 가용성**: 99.9% uptime

### **핵심 가치 제안**
1. **즉시성**: 메시지 전송 후 1초 내 상대방에게 전달
2. **안정성**: 네트워크 끊김, 서버 장애 시에도 메시지 무손실
3. **확장성**: 사용자 증가에 따른 수평 확장 지원
4. **사용성**: 직관적이고 반응형 UI/UX

## 👥 타겟 사용자

### **Primary Users (주요 사용자)**
- **젊은 성인층 (20-35세)**: 실시간 소통을 중시하는 사용자
- **게임/취미 커뮤니티**: 공통 관심사 기반 그룹 채팅 사용자
- **직장인**: 업무/프로젝트 관련 소규모 팀 채팅

### **User Persona**
**"김채팅" (27세, 게임 커뮤니티 운영자)**
- 실시간성을 중요하게 생각
- 이미지/영상 공유를 자주 함
- 모바일과 PC 동시 사용
- 기존 카카오톡/디스코드 사용 경험

## 🔧 기능 명세

### **Core Features (핵심 기능)**

#### **1. 실시간 텍스트 메시지**
- **입력 즉시 전송**: Enter 키 또는 전송 버튼 클릭
- **전송 상태 표시**: 전송 중 → 완료 → 읽음 (선택적)
- **메시지 순서 보장**: 전송 순서대로 표시
- **긴 메시지 지원**: 최대 2,000자

#### **2. 미디어 메시지**
- **지원 포맷**:
  - 이미지: JPEG, PNG, GIF (≤ 20MB)
  - 영상: MP4, MOV (≤ 10초, ≤ 50MB)
- **업로드 플로우**:
  - 드래그 앤 드롭 또는 파일 선택
  - 업로드 진행률 표시 (0-100%)
  - 미리보기 및 전송 확인
- **최적화**:
  - 자동 썸네일 생성
  - CDN을 통한 빠른 로딩
  - 지연 로딩 (lazy loading)

#### **3. 실시간 상호작용**
- **타이핑 인디케이터**: "김채팅님이 입력 중..." (3초 TTL)
- **온라인 상태**: 실시간 접속자 수 표시
- **읽음 확인**: 메시지 읽은 사용자 수 (선택적)

### **Advanced Features (고급 기능)**

#### **4. 메시지 관리**
- **무한 스크롤**: 과거 메시지 자동 로딩
- **메시지 검색**: 텍스트 내용 기반 검색
- **메시지 액션**:
  - 복사하기
  - 답글달기 (Thread)
  - 삭제하기 (본인 메시지만)

#### **5. 방 관리**
- **방 생성**: 제목, 설명, 태그, 공개/비공개 설정
- **멤버 관리**: 초대, 내보내기, 권한 설정
- **방 설정**: 알림 끄기, 배경 변경

## 🎨 사용자 경험 (UX Requirements)

### **사용자 플로우**

#### **신규 사용자 온보딩**
```
1. 랜딩 페이지 접속
2. 닉네임 입력 (게스트 로그인)
3. 방 검색 또는 생성
4. 방 입장
5. 첫 메시지 전송 (60초 내)
```

#### **메시지 전송 플로우**
```
1. 텍스트 입력 또는 파일 선택
2. 전송 버튼 클릭 또는 Enter
3. 전송 상태 표시 (로딩)
4. 상대방 화면에 메시지 표시 (1초 내)
5. 전송 완료 표시 (체크마크)
```

### **UI/UX 원칙**

#### **1. 반응성 (Responsiveness)**
- **모바일 우선**: 375px 이상 모든 기기 지원
- **터치 친화적**: 버튼 크기 최소 44px
- **빠른 피드백**: 모든 액션에 즉시 시각적 피드백

#### **2. 직관성 (Intuitiveness)**
- **친숙한 패턴**: 카카오톡/텔레그램 유사 UI
- **명확한 아이콘**: 전송, 파일, 이모지 등 표준 아이콘
- **일관된 색상**: 주 색상 #3B82F6 (파란색)

#### **3. 접근성 (Accessibility)**
- **키보드 네비게이션**: Tab 키로 모든 요소 접근
- **스크린 리더**: ARIA 레이블 완전 지원
- **고대비 모드**: 시각 장애인 고려

## 🏗️ 기술 요구사항

### **성능 요구사항**
| 항목 | 요구사항 | 측정 방법 |
|-----|----------|----------|
| **초기 로딩** | 3초 내 첫 화면 표시 | Lighthouse 성능 점수 |
| **메시지 전송** | 1초 내 상대방 수신 | WebSocket RTT 측정 |
| **파일 업로드** | 10MB 파일 30초 내 완료 | 업로드 진행률 API |
| **메모리 사용량** | 200MB 이하 (24시간 연속) | 브라우저 메모리 프로파일링 |

### **호환성 요구사항**
- **브라우저**: Chrome 90+, Safari 14+, Firefox 88+, Edge 90+
- **OS**: Windows 10+, macOS 11+, iOS 14+, Android 10+
- **해상도**: 375px ~ 1920px 너비 지원

### **보안 요구사항**
- **HTTPS 필수**: 모든 통신 암호화
- **XSS 방지**: 사용자 입력 sanitization
- **CSRF 보호**: 토큰 기반 인증
- **Rate Limiting**: 분당 60개 메시지 제한

## 📱 플랫폼별 고려사항

### **웹 (Desktop)**
- **키보드 단축키**: Ctrl+Enter 전송, Esc 취소
- **다중 창 지원**: 여러 방 동시 접속
- **파일 드래그 앤 드롭**: 탐색기에서 직접 업로드

### **모바일 (WebView)**
- **터치 제스처**: 스와이프로 사이드바 열기
- **가상 키보드 대응**: 입력창 위치 자동 조정
- **푸시 알림**: 웹 푸시 API 활용

## 🔄 예외 상황 처리

### **네트워크 관련**
- **연결 끊김**: 자동 재연결 시도 (지수 백오프)
- **느린 네트워크**: 압축 및 최적화된 데이터 전송
- **오프라인**: 로컬 큐에 메시지 저장 후 재연결 시 전송

### **서버 관련**
- **서버 점검**: 사용자에게 사전 공지 및 예상 시간 안내
- **과부하**: Rate limiting 및 우선순위 큐 적용
- **데이터 손실**: Redis + MySQL 이중 백업

### **사용자 관련**
- **잘못된 입력**: 실시간 유효성 검사 및 가이드
- **파일 업로드 실패**: 재시도 버튼 및 오류 원인 설명
- **브라우저 호환성**: 지원하지 않는 기능 대체 제공
